# GrazySAI на Android

**Русский** | [English](README.en.md)

Это попытка перенести GrazySAI — бесплатную рисовалку и анимацию на Rust, сделанную по образцу
PaintTool SAI 2, — на телефон и планшет. Движок тот же, что в настольной версии
([grazyping/GrazySAI](https://github.com/grazyping/GrazySAI), 1.4.6): кисти, слои, таймлайн, 3D
и форматы файлов работают. Не работает пока главное для телефона — удобный интерфейс.

![GrazySAI на Android](docs/screenshot.png)

## Честно о состоянии

Порт в разработке. Интерфейс под телефон **очень сырой**: кнопки местами мелкие, панели
перекрывают друг друга, жестов почти нет, на низких экранах что-то обрезается. Бывают падения.
APK публикую, чтобы можно было пощупать и написать, что именно неудобно, а не потому, что этим
уже можно заменить SAI на планшете.

## Попробовать

1. Скачайте `GrazySAI-<версия>-android-arm64-v8a.apk` со страницы
   [Releases](https://github.com/avsiel/GrazySAI-on-android/releases/latest).
2. Разрешите браузеру или файловому менеджеру ставить приложения из неизвестных источников.
3. Установите и запустите. При первом открытии файлов приложение попросит доступ ко всем файлам —
   без него видна только его собственная папка.

Нужен Android 7.0+ (minSdk 24) и процессор arm64-v8a. APK весит около 48 МБ, потому что внутри
весь нативный движок.

## Что уже работает

Рисование:
- кисти как в SAI — карандаш, аэрограф, акварель, маркер, ластик, со смешиванием краски
  с холстом и стабилизатором;
- слои с папками, масками, обрезкой и всеми 28 режимами наложения, эффекты и стили слоя,
  текстура бумаги;
- выделения, заливка, фильтры, линейки, кривые, текстовые слои;
- импорт кистей из SAI 2, Photoshop, Krita и Clip Studio.

Анимация и 3D: таймлайн с целлами и onion skin, экспорт в GIF, APNG, PNG-кадры и MP4, кукольная
деформация, 3D-слои из glTF, VRM, OBJ, FBX, PMX и COLLADA с переводом в контуры.

Файлы: `.sai2` (SAI 2 их открывает), PSD и PSB со слоями, OpenRaster, PNG, JPEG, WebP, TIFF,
BMP, TGA, QOI.

Перо: давление, наклон и поворот. Проверял на Lenovo Precision Pen 3, по другим моделям отзывов
пока нет. Если давление не работает, строка `GrazySAI: paint_app: давление: force=...` в logcat
покажет, что приходит.

## Что было сделано ради Android

Окно редактора запускается внутри `android.app.NativeActivity`, поэтому на телефоне открывается
не урезанный просмотрщик, а сам `paint-app`. Добавлены полноэкранный режим с учётом системных
отступов, масштаб интерфейса 75–250% отдельно от системного, проводник в стиле SAI по `/sdcard`
и чтение давления и наклона из `MotionEvent`. Пришлось пропатчить `winit`, `rfd` и `arboard` —
подробности в [`android/README.md`](android/README.md).

## Ограничения этой сборки

- APK подписан debug-ключом Android SDK. Ставьте обновления только поверх этой сборки, иначе
  Android откажется.
- Собрано только под arm64-v8a, `armeabi-v7a` и `x86_64` нет.
- Доступ ко всем файлам (`MANAGE_EXTERNAL_STORAGE`) нужен на Android 11+, иначе проводник видит
  лишь папку приложения.

Если что-то сломалось — пишите в [Issues](https://github.com/avsiel/GrazySAI-on-android/issues).
Больше всего помогают файл, на котором воспроизводится проблема, и модель устройства.

## Сборка

Нужны Rust с `cargo-ndk`, Android SDK (build-tools, platform android-34) и NDK:

```powershell
.\android\build_apk.ps1              # arm64-v8a, подпись debug-ключом
.\android\build_apk.ps1 -SkipRust    # пересобрать APK из готовых библиотек
```

Скрипт прогоняет `cargo ndk build --release -p paint-android-full`, потом `aapt2`, `zipalign` и
`apksigner`, результат — `GrazySAI-android.apk` в корне.

## Что в репозитории

| Каталог | Что там |
|---|---|
| `crates/paint-core` | Пиксели, тайлы, слои, смешивание, кисти, штрихи, векторы, ресемплинг, анимация, кукольная деформация |
| `crates/paint-formats` | Чтение и запись `.sai2`, PSD, OpenRaster и картинок |
| `crates/paint-app` | Окно редактора на egui, переводы в `lang/` |
| `crates/paint-android-full` | `cdylib` с `android_main` для APK |
| `crates/paint-3d` | 3D-модели: чтение, позы, рендер, экспорт в GLB и OBJ |
| `crates/paint-studio`, `paint-convert`, `paint-cli` | Мастерская кистей, конвертер, консоль — настольные, в APK не входят |
| `android/` | Манифест, ресурсы, `build_apk.ps1`, заметки по порту |
| `vendor/` | Пропатченные `winit`, `rfd`, `arboard` |
| `docs/` | План, формат `.sai2`, правила программы, проверки |
| `tools/` | Выпуск настольных сборок |

Настольная версия с руководством — [grazyping/GrazySAI](https://github.com/grazyping/GrazySAI).
