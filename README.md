# GrazySAI на Android

**Русский** | [English](README.en.md)

Это мой порт GrazySAI на телефоны и планшеты. GrazySAI — бесплатная рисовалка с анимацией на Rust, сделанная по образцу PaintTool SAI 2 ([оригинал для ПК](https://github.com/grazyping/GrazySAI), версия 1.4.6).

Движок здесь тот же, что на компьютере, так что кисти, слои, таймлайн, 3D и файлы работают. Главная проблема — интерфейс: он пока не приспособлен под телефон.

![GrazySAI на Android](docs/screenshot.png)

## Честно о состоянии

Порт ещё сырой. Кнопки местами мелкие, панели налезают друг на друга, жестов почти нет, а на невысоких экранах часть интерфейса обрезается. Иногда приложение вылетает.

Я выкладываю APK не потому, что им уже можно заменить SAI на планшете, а чтобы вы попробовали и написали, что неудобно.

## Как установить

1. Скачайте `GrazySAI-<версия>-android-arm64-v8a.apk` на странице [Releases](https://github.com/avsiel/GrazySAI-on-android/releases/latest).
2. Разрешите браузеру или файловому менеджеру устанавливать приложения из неизвестных источников.
3. Установите и запустите.

При первом открытии файлов приложение попросит доступ ко всем файлам. Без него оно видит только свою папку.

Что нужно: Android 7.0 или новее и процессор arm64-v8a. Весит APK около 48 МБ, потому что внутри весь движок.

## Что умеет

**Рисование.** Кисти как в SAI: карандаш, аэрограф, акварель, маркер и ластик. Краска смешивается с холстом, есть стабилизатор. Слои с папками, масками и обтравкой, 28 режимов наложения, эффекты, стили слоя и текстура бумаги. Также выделения, заливка, фильтры, линейки, кривые и текстовые слои. Кисти можно импортировать из SAI 2, Photoshop, Krita и Clip Studio.

**Анимация и 3D.** Таймлайн с onion skin, экспорт в GIF, APNG, MP4 и PNG-кадры, кукольная деформация. 3D-модели (glTF, VRM, OBJ, FBX, PMX, COLLADA) можно вставить слоем и перевести в контуры.

**Файлы.** `.sai2` (его открывает сам SAI 2), PSD и PSB со слоями, OpenRaster, PNG, JPEG, WebP, TIFF, BMP, TGA, QOI.

**Перо.** Поддерживаются нажим, наклон и поворот. Я проверял только на Lenovo Precision Pen 3, про другие стилусы пока ничего не знаю. Если нажим не работает, найдите в logcat строку `GrazySAI: paint_app: давление: force=...` — по ней видно, что приходит от пера.

## Что я переделал под Android

- Редактор запускается через `android.app.NativeActivity`, поэтому на телефоне открывается настоящий `paint-app`, а не урезанный просмотрщик.
- Добавил полноэкранный режим с учётом системных отступов.
- Масштаб интерфейса меняется от 75 до 250% независимо от системного.
- Сделал проводник в стиле SAI для `/sdcard`.
- Нажим и наклон берутся из `MotionEvent`.
- Пришлось исправить `winit`, `rfd` и `arboard`. Подробности в [`android/README.md`](android/README.md).

## Ограничения

- APK подписан debug-ключом Android SDK. Обновлять можно только поверх этой же сборки, иначе Android откажется ставить.
- Есть только arm64-v8a. Для `armeabi-v7a` и `x86_64` сборки нет.
- На Android 11+ нужно разрешение «доступ ко всем файлам» (`MANAGE_EXTERNAL_STORAGE`), иначе проводник видит только папку приложения.

Если что-то сломалось, пишите в [Issues](https://github.com/avsiel/GrazySAI-on-android/issues). Мне очень поможет файл, на котором воспроизводится ошибка, и название вашего устройства.

## Сборка

Понадобятся Rust с `cargo-ndk`, Android SDK (build-tools и platform android-34) и NDK.

```powershell
.\android\build_apk.ps1              # arm64-v8a, подпись debug-ключом
.\android\build_apk.ps1 -SkipRust    # пересобрать APK из готовых библиотек
```

Скрипт запускает `cargo ndk build --release -p paint-android-full`, затем `aapt2`, `zipalign` и `apksigner`. Результат — файл `GrazySAI-android.apk` в корне репозитория.

## Что где лежит

| Каталог | Что внутри |
|---|---|
| `crates/paint-core` | Пиксели, тайлы, слои, смешивание, кисти, штрихи, векторы, ресемплинг, анимация, кукольная деформация |
| `crates/paint-formats` | Чтение и запись `.sai2`, PSD, OpenRaster и обычных картинок |
| `crates/paint-app` | Окно редактора на egui, переводы в `lang/` |
| `crates/paint-android-full` | `cdylib` с `android_main` для APK |
| `crates/paint-3d` | 3D-модели: чтение, позы, рендер, экспорт в GLB и OBJ |
| `crates/paint-studio`, `paint-convert`, `paint-cli` | Мастерская кистей, конвертер и консольная утилита. Только для ПК, в APK не входят |
| `android/` | Манифест, ресурсы, `build_apk.ps1`, заметки по порту |
| `vendor/` | Исправленные `winit`, `rfd`, `arboard` |
| `docs/` | План, описание формата `.sai2`, правила программы, проверки |
| `tools/` | Скрипты для выпуска ПК-сборок |

Версия для компьютера с руководством: [grazyping/GrazySAI](https://github.com/grazyping/GrazySAI).
